Sync settings

Admins only. If the app has a shared sync address set in config.json, regular devices already sync with no setup — a token here just connects this device straight to GitHub instead.

Connect a GitHub repo to store data centrally — every device that opens this app with the same settings reads and writes the same file. Use a fine-grained personal access token scoped to just this one repo, with Contents: Read and write permission and nothing else. The token is stored only in this browser's local storage — never sent anywhere but GitHub's API. Each browser/device needs to be connected separately (this includes an "Add to Home Screen" icon, which can have its own separate storage from the regular browser on some phones — if data looks missing right after installing the icon, this screen is where you reconnect it). See the README for a link format that pre-fills everything but the token, to make that quick.
